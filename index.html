The Colosseum

App display name: "The Colosseum" — a desktop app to configure, draft, and publish custom video game tournaments.

What this app does

  • Let an administrator create a tournament: name, game, date/time, sign-up deadline, draft style, player limits.
  • Auto-update an existing Google Forms sign-up template with tournament details (title, date/time, questions).
  • Provide a draft board (randomized picker wheel or manual draft) and timers.
  • Push finalized teams and schedule to a Challonge bracket (via Challonge API).
  • Allow edits prior to start and trigger start events across integrations.

Why this app requests Google access

To update an existing Google Forms template with tournament details the app requests access to the Google Forms API via OAuth. The app requests only the minimum scopes required to edit a specific form and does not request broad access to unrelated Google data.

OAuth tokens and third-party credentials are stored locally on the administrator's machine (OS keychain or encrypted local store). Tokens are not sent to any external servers by default.

Other integrations & data

  • Challonge: used only to create or update the tournament bracket. Challonge credentials are requested and stored locally.
  • We do not collect or share personal data beyond what the administrator enters for tournament configuration and what users submit via Google Forms.
